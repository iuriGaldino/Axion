# Guia de Contribuição - AXION

Bem-vindo ao projeto AXION!

## Estratégia de Branches (Git Flow)
- `main`: Código estável em produção.
- `develop`: Código em integração para a próxima release.
- `feature/*`: Novas funcionalidades.
- `bugfix/*`: Correções de bugs.

## Como Contribuir
1. Crie uma branch a partir da `develop`.
2. Garanta que todos os testes passem (`make test`).
3. Abra um Pull Request utilizando o template oficial.
4. Aguarde a revisão de código.

## Padrões de Código
- Go: Siga as recomendações do `golangci-lint`.
- Kotlin: Siga o guia de estilo oficial da JetBrains.
