# Guia de IA para Desenvolvedores - AXION

## Ferramentas Recomendadas
- **Cursor:** Utilize para refatoração de UseCases seguindo Clean Architecture.
- **Continue.dev:** Ótimo para geração de testes unitários com o modelo local Qwen.
- **OpenWebUI:** Para testar prompts de insights financeiros rapidamente.

## Prompt Engineering
Sempre forneça o contexto do DDD para a IA:
"Aja como um arquiteto Go, implemente este UseCase seguindo os padrões de domínio definidos em internal/domain..."
