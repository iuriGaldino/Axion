# Modelo de Dados - AXION

## Entidades Principais
- **Users:** Armazena credenciais e preferências.
- **Transactions:** Registro de entradas e saídas.
- **Categories:** Classificação de gastos.
- **Budgets:** Limites de gastos por categoria.
- **Goals:** Metas de economia a longo prazo.
